# ETC PHOTOS

A responsive, editorial-style automotive photography portfolio.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive design, themes and animations
- `script.js` — gallery filters, full-screen viewer, slideshow, theme switch and enquiry form
- `favicon.svg` — browser icon

## Before publishing
1. Open `script.js` and replace `YOUR_EMAIL_HERE` with the email address that should receive enquiries.
2. Replace `YOUR_INSTAGRAM_HANDLE` in `ETC_CONFIG.instagramUrl` with the real Instagram username.
3. Replace the sample gallery and journal images in `index.html` with your own photographs. The current images are illustrative placeholders loaded from Unsplash.
4. Add your real package prices, testimonials and business/about details before making those sections public. The current package descriptions are starting points and do not claim fixed prices.
5. Test the contact form on a device with an email app configured. It opens a pre-filled email; it does not send messages to a server.

## Preview locally
Open `index.html` in a browser, or use a local static server.

## GitHub Pages
In the repository, open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save. GitHub will provide the published site URL when deployment completes.

## Notes
The site uses Google Fonts and remote Unsplash sample photography, so those assets need an internet connection. The theme preference is stored in the visitor's browser.
